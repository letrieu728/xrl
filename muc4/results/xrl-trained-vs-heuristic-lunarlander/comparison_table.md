F1 reported is weighted F1 (paper §5.2) plus macro F1. Global-cause sets for BART-weighted = predecessors of each action node in the collapsed causal graph from the FIDELITY-stage HTE refit (a separate stochastic fit from the graph-stage checkpoints, because bart_train has no seed — see per-run details). Time = structure-learning seconds (sum over 12 per-target checkpoints; infer only, excluding rollout and fidelity).
