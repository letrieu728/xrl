LunarLander 95% edges should therefore be quoted with their CI level, and the 23-edge 99% set (not the 39-edge 95% set) is the stricter-threshold core.

## Repeatability note (observed in this task)

A single-target pilot run (target `x` only, same script, same seed 0, separate process) found `x ← {x}` at 95%, while the full run found `x ← {x, vx}` — the `vx → x` pair was significant at 90% in the pilot and flipped at 95% between processes. Same code, same seeds, one borderline edge differs: direct evidence that BART/HTE decisions on borderline pairs vary run to run (threaded BART fitting / tree tie-breaking), independent of the split seed. The 95% validation above (0 mismatches) is internal to ONE fit and is unaffected; it does not claim cross-run stability.
